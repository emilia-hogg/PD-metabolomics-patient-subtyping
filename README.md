# PD-metabolomics-patient-subtyping

All scripts use the shared configuration file `00_config/config.R`, which defines the project paths, external data inputs and analysis settings. The pipeline requires two external input datasets that are not included in the repository; their local paths must be specified in `config.R` before running the pipeline. Full setup instructions are provided in `DATA_SETUP.md`.

A table (Appendix 2) outlining the pipeline architecture is included in the dissertation (not in this repository).
